# EstudosDIO
Repositório para estudos pela plataforma DIO

# Tema
O tema escolhido foi Dungeons & Dragons 5.5ed.

# Objetivo
Ter um auxiliar para consultar regras e informações sobre a versão 5.5 do RPG Dungeons & Dragons, facilitando assim o trabalho de criação de personagem e criação de aventuras de RPG.

# Fontes
Não tive muitas opções de conteúdos além dos próprios livros em PDF, acabei incluindo um vídeo do youtube que destaca algumas diferenças da versão anterior imaginando que seria de grande ajuda ter essa informação de "o que mudou". No mais utilizei o Deep Research para testar e procurar fontes que ajudem na criação de aventuras, acabara surgindo muitas fontes desconhecidas por mim, mas que acabaram sendo interessantes para expandir as possibilidades.

# Perguntas
Perguntei de forma básica sobre a criação de personagem, para que ele me ajudasse, inclusive pedi que ele criasse um personagem com algumas características especificas e ele concluiu a tarefa de forma bem correta utilizando o livro do jogador como fonte principal. Também pedi um mapa mental da criação de personagem.

Outra pergunta interessante foi: Como faço para usar uma magia de mago nível 1. Ele usou o livro do jogador para explicar passo a passo como faço para utilizar a magia de mago seguindo as regras corretas.
